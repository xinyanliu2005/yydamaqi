# 马蹄哒哒哒· 飞行棋网页版

一个 2–4 人在线飞行棋，支持英雄技能和卡牌对战。[index.html](index.html) + [src/](src/) 是真正
运行的多文件源码（浏览器原生 ES module，不需要打包/构建步骤），部署在 Netlify 上，任何人拿到
链接都能直接玩，不需要登录任何账号。跨设备的共享房间状态同步用 Supabase（Postgres）
（见 [src/supabase-db.js](src/supabase-db.js)）。

> 这个项目最早是作为 Claude Artifact 发布的（单文件、通过 Claude 的 `db` 运行时能力同步状态），
> 后来因为 Artifact 的分享权限被限制、朋友打不开链接，迁移到了 Netlify 静态托管；共享状态的后端
> 换过两次——先是 Firebase Firestore（Google 的基础设施，中国大陆用户不开 VPN 完全连不上），
> 后来换成腾讯云开发 CloudBase（国内可访问，但免费体验环境到期后需要每月约 20 元的付费套餐），
> 最后定在 Supabase（免费额度长期有效，国内访问较慢但并非完全屏蔽——如果之后发现访问质量不
> 可接受，CloudBase 那一套仍然是验证过可行的备选，历史代码在 git 记录里）。

## 部署前需要做的事

**1. Supabase 项目**（共享房间状态存在这里）：
1. https://supabase.com/dashboard → 新建项目（免费额度长期有效，不是限时试用）。
2. 左侧 SQL Editor → 新建查询 → 把仓库根目录 [supabase-setup.sql](supabase-setup.sql) 的内容
   整段粘贴进去执行一次。这会建好 `games` 表、开放匿名读写的安全策略、并打开这张表的实时推送。
3. Project Settings → API → 复制 **Project URL** 和 **anon / publishable key**，分别填进
   [src/supabase-config.js](src/supabase-config.js) 的 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`，
   替换掉 `REPLACE_ME`。这个 key 是设计给浏览器用的，可以放心提交到仓库里——真正的访问控制
   在上一步的安全策略（RLS policy），不是靠隐藏这个 key。

**2. 部署到 Netlify**：这是纯静态站点，没有构建步骤。
- 如果通过 Git 连接：app.netlify.com → Add new site → Import an existing project →
  选这个仓库 → Publish directory 填 `.`（仓库根目录），Build command 留空。
- 仓库里的 [netlify.toml](netlify.toml) 已经写好了这两项，Netlify 通常会自动识别。
- 之后每次 push 到关联的分支，Netlify 会自动重新部署——**这次迁移之后没有额外的部署步骤了**
  （不像 CloudBase 那版还需要单独部署一个云函数）。

## 当前玩法规则（已实现）

0. **两种对战模式**（创建房间时选择，加入的人跟着房间已经定好的模式走）：
   - **单人混战（1vN，默认）**：2–4 人，没有队伍，其他所有人都是对手；率先到达终点的那一个人获胜。
   - **组队 2v2**：正好 4 人，进大厅之后由**房主**把每个人分到 A、B 两队（两队各 2 人，凑不齐不能开始游戏）；**队里任意一人先到终点，整个队伍就算获胜**（结算时会同时报出队友的名字）。这个模式下，阴阳迷踪步/清风霁月/妙手回春这三张"增益"卡可以选择用给自己还是队友；金玉手/梁上君子/摄星拿月/凌虚一指/叨叨不叨叨这类"针对敌方"的卡不能对自己的队友使用（客户端选目标时会先排除掉队友，服务端也会再校验一次）；青溪、墨山道两名英雄跟"队友"相关的被动只在这个模式下才会真正触发，见下方英雄说明。
1. **人数**：单人混战每局 2–4 人，组队模式固定 4 人；创建/加入房间后各自选英雄。
2. **回合顺序**：开局时随机决定先后手，这个顺序就是每一"轮"（round）里各玩家依次行动的顺序。
3. **每一轮开始**：**所有玩家同时**免费获得 +30 元、+2 张随机卡牌，直接进各自口袋（手牌），不收费——不是等到某个人自己的回合才发。开局是第 1 轮；之后每当顺序轮完一整圈、回到最先手的玩家时，就开始新的一轮，再同时发一次。金钱和手牌是累加的，不会重置。
4. **商店**：随时可以打开商店页签，里面随机上架 5 张**互不重复**的卡牌（价格见下表），花钱买下的卡牌立刻进口袋、并从这一页下架。口袋里不想要的卡牌可以随时卖出——商店价 30 元的卡卖 8 元，其余卡固定卖 5 元。商店购买/卖出不占用回合，不受"是否轮到你"限制，**而且完全私密**：别人看不到你在商店买了什么、卖了什么、换了几次批。
   - **每一轮开始，商店会自动刷新成全新的 5 张卡**（不占用"换一批"的次数/费用）——就算你上一轮买剩 4 张、3 张都没关系，新的一轮开始时又是满满 5 张。想在同一轮内立刻看到新的一批，才需要手动"换一批"（收费，见下）。
   - **"换一批"价格阶梯**：在你自己本回合开始后，第 1 次换一批免费，第 2 次 5 元，第 3 次及以后每次 10 元；这个计数在你下一次自己的回合开始时重置。
   - **卡牌概率分阶段，商店和免费发牌（每轮的2张、千金取义抽的2张）都遵守同一套权重**：开局前 2 轮以阴阳迷踪步/生财有道/清风霁月/金玉手和被动卡（含散财消灾）为主，凌虚一指/凌云踏/千里目/一掷千金很少见，其余卡（含破釜沉舟）完全不会出现；第 3 轮起，凌虚一指/凌云踏/叨叨不叨叨/摄星拿月/梁上君子/破釜沉舟/千里目/一掷千金这类干扰/进攻卡变成主流；一旦有玩家率先冲到全程 80%（第 80 格，**在那一轮结束时才盘点、生效**，不是踩到的瞬间立刻生效），**其他玩家**（不是冲线的那个人）抽到"奇袭"类卡牌（凌虚一指/狮吼正声/敲山震虎）的概率会提高，狮吼正声和敲山震虎在这之前完全不会出现。这套概率数值还在摸索阶段，后续会继续调整。
5. **回合内可做的事**（任意顺序、任意次数，掷骰子前后都可以继续用技能/打牌）：
   - 使用一次英雄主动技能（受技能冷却限制，见下）
   - 打出口袋里的卡牌（**打出免费，不再收费**——价格只在商店购买时收）
   - 掷骰子结算本回合的移动步数（步数 = 骰子点数 + 增益 − 减益，最低为 0）
   - 结束回合——**不要求必须先掷骰子**，可以直接放弃本回合的移动，结束回合
6. **技能冷却**：主动技能用一次后默认进入 2 回合冷却——比如第 1 回合用了，第 2 回合不能用，第 3 回合才能再用。冷却在"这名玩家自己的回合开始时"递减。文津馆的冷却只有 1 回合（相当于每次轮到自己都能用）；狂澜的冷却取决于本次是否真正命中（见英雄说明）。
7. **同一效果叠加**：如果某个 buff/debuff 已经在身上生效，再次触发同一来源（同一张卡 / 同一个技能）的效果时，不会把数值继续相加，而是把剩余回合数相加——例如阴阳迷踪步用两次仍然只是 +5 步，但持续时间从 2 回合变成 4 回合。不同来源的效果之间互不影响，各自独立叠加数值（比如一个 +5 步的buff 和另一个来源的 +3 步 buff 同时存在，合计仍是 +8 步）。
8. **胜利条件**：率先到达第 99 格。
9. **特殊格子**：棋盘上有 12 种特殊效果，每局开始时随机各分配到一个格子上（0 起点和 99 终点不会有）——棋盘上会用紫色边框 + 小标记标出来，不管是自己走到的还是被卡牌/技能打过去的，只要最终停在那一格就会触发：
   - **无相皇**：下一回合无法使用主动技能（可被清风霁月解除）。
   - **千夜**：接下来 2 回合 −3 步（可被清风霁月解除）。
   - **张万师**：立即掷一次骰子，并倒退相应的格数（倒退不会走到负数格，最多退到起点）。
   - **太平钟楼**：下一轮，全场禁止使用奇袭类卡牌（凌虚一指/狮吼正声/敲山震虎）和执锐系主动技能（狂澜/孤云）；同一轮内不管多少人踩中都只算一次，不会因为多人重复触发而延长。
   - **常平仓**：所有玩家立即获得 50 元。
   - **鬼市**：随机偷走其他玩家的 2 张卡牌（可能来自同一人，也可能分属不同人，内容对其他人保密）。
   - **崇元殿**：下一次掷骰额外 +5 步。
   - **飞天残垣**：立即获得一张【凌云踏】。
   - **鲁菜**：从 20 元 / 下回合 +3 步 / 2 张随机卡牌里**任选一项**——必须先选完，才能继续掷骰子或结束回合（不影响其他玩家的操作，只卡住这名玩家和"轮到谁"的推进）。
   - **熔炉**：立即获得 2 张随机卡牌，然后**必须**从手牌（含刚获得的这 2 张）里弃置 2 张——同样要处理完才能继续掷骰子或结束回合。
   - **竹林小屋**：接下来 2 回合 +3 步。
   - **不羡仙**：清除自身当前**所有**减益（不同于清风霁月一次只解一项）。
9. **横幅播报**：屏幕顶部会用一条醒目的横幅显示最新一条对局动态——谁用了什么技能/卡牌、谁掷出了几步、谁被跳过了回合等等。这些是"会实际影响场上局势"的公开信息；商店里的买/卖/换一批不算在内，只有你自己看得到。

## 英雄（已实现）

| 英雄 | 主动技能 | 被动技能 |
|---|---|---|
| 天泉 | 千金取义：花 20 元获得 2 张随机卡牌 | 非自己回合内失去钱，获得「失去金额 ÷ 3」的步数增益（向下取整；目前由"梁上君子"触发——被梁上君子偷走多少钱，就获得多少÷3的步数） |
| 醉花阴 | 花醉三千：对**场上所有其他玩家**施加 −3 步减益，持续 2 回合（不用挑目标，一次性打所有人） | 场上有敌人带减益时，自己额外 +3 步 |
| 孤云 | 大道无为（冷却2回合）：朝场上**除自己以外**最靠近终点的玩家靠近——相距 ≤6 格则直接移动到对方所在格，否则朝对方方向移动 6 格；如果自己已经是全场第一，则改为朝落后自己最多的对手移动，方向可能是往回走。移动后立刻获得一张【凌虚一指】 | 落后于领先者 3-4 格时 +2 步，5-9 格时 +5 步，10 格及以上时 +7 步 |
| 文津馆 | 运筹帷幄（冷却1回合）：投两次骰子，取点数较大的一次结算本回合移动（这一次投掷本身就是本回合的骰子结算，不用再单独点"掷骰子"） | 本回合的移动如果越过了某名玩家的位置，可以再掷一次骰子；只要还在越过别人，就能连续触发。**任何形式的移动都算**——掷骰子移动、打出"凌云踏"这类卡牌的位移，只要越过了别人，都会触发再掷一次 |
| 狂澜 | 军威赫赫：对当前位置前后 6 格内的**所有**玩家发起奇袭，使其跳过下一回合（可被无相金身格挡；已处于保护状态的玩家免疫）。无论奇袭是否命中，被扫到的玩家都会**随机移除自身一项效果**。若这次无人被真正命中（0 命中），下一回合仍可再次使用（不进入冷却）；若有人被命中，则进入 2 回合冷却，并让自己前进 6 格 | 每次使用主动技能，自己获得 +3 步（用于紧接着的下一次掷骰子） |
| 青溪 | 坐看云起（冷却2回合）：获得一张【妙手回春】（见下方卡牌表） | **组队模式专属**：队友被奇袭命中时，自己可以出面化解——从队友身上拿走 15 元或 1 张卡牌（各 50% 概率，缺哪样就改拿另一样）；同一轮内为同一名队友化解多次，代价翻倍；队友（翻倍后）金钱/卡牌都不够时不生效。单人混战模式下没有队友，这条被动不生效 |
| 墨山道 | 兼爱非攻（冷却2回合）：自己获得 2 张随机卡牌（组队模式下，队友也会同时获得 2 张） | 这一轮里打出过的卡牌种类数会转化为掷骰步数加成：1 种 +1 步，2 种及以上 +2 步（本回合封顶 +2 步；组队模式下会把队友这一轮打出的种类也并进来一起算） |
| 梨园 | 请君打榜（冷却2回合）：随机从一名敌方玩家身上偷取 15 元或 1 张随机卡牌（各 50% 概率，对方缺哪样就改偷另一样，两样都没有则一无所获） | 落后当前第一名超过 5 格时 +4 步；自己就是第一名时不触发 |

**关于"奇袭"效果的补充说明**（凌虚一指、狂澜的军威赫赫都属于奇袭）：
- 一名玩家一旦被奇袭命中（即将跳过下一回合），在这次跳过真正发生之前处于**保护状态**，不能再被任何奇袭选为目标，必须等TA的回合被跳过、保护解除后才能再次被奇袭命中。
- 狂澜的"随机移除自身一项效果"是无差别的，不受保护状态影响——即使某名玩家已经处于保护状态（免疫本次奇袭的"跳过回合"部分），只要在 6 格范围内，仍然会被随机抽走一项自身效果（这项被抽走的效果甚至可能正好是保护状态本身，但即使如此也不会被追加视为这次奇袭"命中"了）。

**天泉的开局福利**（只发生一次，不是每轮都有）：游戏刚开始时，场上每一个天泉玩家都会给所有**其他**玩家（哪怕对方也是天泉）+40 元，自己额外 +90 元。举例：局里只有 1 个天泉时，其他人开局是 30（每轮基础发放）+40=70 元，天泉自己是 30+90=120 元。多个天泉会互相叠加——两个天泉的话，彼此都会从对方那里再拿到一份 +40（不只是自己的 +90），普通玩家则会拿到两份 +40。

## 卡牌（已实现）

价格是**商店购买价**，打出手中卡牌本身不收费；卖出的话，商店价 30 元的卡卖 8 元，其余卡固定卖 5 元。

| 卡牌 | 商店价 | 效果 |
|---|---|---|
| 阴阳迷踪步 | 20 元 | 自身 +5 步，持续 2 回合 |
| 生财有道 | 15 元 | 接下来 2 回合，按该回合最终步数获得等额金钱 |
| 清风霁月 | 15 元 | 解除自身一项减益（可解除「花醉三千」造成的减益） |
| 金玉手 | 15 元 | 对一名敌方玩家施加减益，使其 −3 步 |
| 无相金身 *（被动）* | 15 元 | 留在口袋里就一直生效：抵御一次「奇袭」类卡牌，格挡后自身消耗掉；若目标同时持有「散财消灾」，优先触发散财消灾 |
| 凌虚一指 *（奇袭）* | 15 元 | 对当前位置前后 2 格内的一名玩家使用（自己持有「千里目」则变为 4 格），使其**跳过下一个回合**；若对方持有「散财消灾」/「无相金身」则被防住、无效 |
| 梁上君子 | 15 元 | 偷走一名玩家 15 元（对方不足 15 元则偷走其全部金钱） |
| 摄星拿月 | 20 元 | 从一名玩家手牌中**随机偷走 1 张**卡牌（不会公开是哪一张，保持手牌保密） |
| 好兆骰 *（被动）* | 30 元 | 留在口袋里就一直生效：掷骰点数 1-2 时额外 +3 步，4-5 时额外 +2 步，6 时额外 +1 步（点数为 3 时无加成） |
| 凌云踏 | 15 元 | 打出后立即选择向前跳 3/4/5/6 格中的一档，与本回合骰子移动叠加 |
| 飒沓流星 *（被动）* | 30 元 | 留在口袋里就一直生效：自己**每一次成功命中**的奇袭（不含被格挡/被保护免疫的）都额外让自己前进 6 格；狂澜一次奇袭命中好几个人，就触发好几次 |
| 叨叨不叨叨 | 15 元 | 销毁一名玩家手牌中随机 1 张卡牌，对方没有任何补偿（和摄星拿月的区别：这张卡是销毁，不是偷） |
| 狮吼正声 *（奇袭）* | 30 元 | 无视距离，直接对**当前排名第一**的玩家发起奇袭（如果自己就是第一，则改打第二名）；命中后目标跳过下一回合、并额外倒退 5 格。同样可被「无相金身」格挡，对处于保护状态的玩家无效 |
| 聚宝盆 *（被动）* | 30 元 | 留在口袋里就一直生效：自己金钱超过 30 元时 +2 步，超过 80 元时改为 +4 步（两档不叠加，取最高档） |
| 敲山震虎 *（奇袭）* | 20 元 | 无视距离，直接对**当前排名第一**的玩家发起奇袭（如果自己就是第一，则改打第二名），使其跳过下一回合；同样可被防住，对处于保护状态的玩家无效。**只有在场上有玩家率先冲到全程 80% 之后，商店才会上架这张卡** |
| 破釜沉舟 | 15 元 | 立即花费 20 元，获得 2 张【凌虚一指】（金钱不足 20 元时无法使用；第 3 轮起商店才常见这张卡） |
| 散财消灾 *（被动）* | 20 元 | 留在口袋里就一直生效：被「奇袭」命中时改为损失 20 元、不会跳过回合（**优先级高于无相金身**）；若金钱不足 20 元，这张卡不生效，本次奇袭正常命中。触发一次就消耗掉 |
| 千里目 *（被动）* | 30 元 | 留在口袋里就一直生效：自己发起的【凌虚一指】奇袭距离限制额外 +2 格（2→4 格） |
| 一掷千金 | 20 元 | 押上全部身家：花光当前所有金钱，立即前进「花掉的钱 ÷ 5」步，最多前进 15 步（向下取整） |
| 妙手回春 | **无法在商店购买**，只能通过青溪的【坐看云起】获得 | 单人混战模式下不用挑目标，直接对自己生效；组队模式下可以选自己还是队友——若目标当前没有减益，获得 +4 步增益（持续 2 回合）；若目标有减益，则清除**所有**减益，并改为获得 +2 步增益（持续 2 回合） |

**被动卡牌**（无相金身、好兆骰、飒沓流星、聚宝盆、散财消灾、千里目）不通过"使用"按钮触发——只要留在手牌里就自动生效，界面上也不会显示使用按钮，只能卖出。

**同名效果叠加**：如果某个 buff/debuff 已经在身上生效，同一来源（同一张卡/同一个技能）再次触发时不会把数值继续相加，而是把剩余回合数相加。

**奇袭的"保护状态"**：这条规则**不适用于**"凌虚一指"的跳过回合效果——一名玩家一旦被奇袭命中（即将跳过下一个回合），在这次跳过真正发生之前处于保护状态，不能再被任何奇袭类效果选为目标，必须等TA的回合被跳过、保护解除后才能再次被奇袭。

## 尚未实现 / 待补充设计（需要你给具体数值和描述）

- **更多英雄**：目前有天泉、醉花阴、孤云、文津馆、狂澜、青溪、墨山道、梨园八个。
- **更多卡牌**：目前有 20 张（含只能靠技能获得、商店买不到的妙手回春）。
- **更多特殊格子**：目前 12 种，见上面"当前玩法规则"里的清单；每种目前只在棋盘上出现一次，位置每局随机。
- 组队模式（2v2）目前只有"任意一人先到终点、整队获胜"这一种规则；没有队伍内部的额外互动（比如共享手牌、组队专属卡牌）之类的扩展玩法，也没有对狂澜/醉花阴/孤云/梨园这几个英雄的技能做"排除队友"的处理——这几个技能目前在2v2模式下仍然会影响到队友（见上面英雄说明，这是已知的范围限制，不是bug）。
- 断线重连 / 在线状态显示：目前没做，玩家中途关掉页面，其他人只能等待。
- 手牌保密目前是"界面级"而非加密级——所有房间数据都在共享存储里，理论上打开开发者工具能看到别人的手牌，正常点开页面玩不会看到。

## 代码结构

源码在 [src/](src/) 下按职责拆成几个 ES module，每个文件都有注释标出用途：

| 文件 | 内容 |
|---|---|
| [src/data.js](src/data.js) | `HEROES` / `CARDS` / `PLAYER_COLORS` / `WIN_POS` / `STORE_REFRESH_PRICES` 静态数据表。加新英雄/卡牌从这里加一条即可，逻辑代码不用大改。 |
| [src/utils.js](src/utils.js) | 与游戏规则无关的通用工具函数（uid、洗牌、生成房间号、HTML 转义…）。 |
| [src/game-logic.js](src/game-logic.js) | 游戏规则用的辅助函数：查玩家、判断当前回合、buff 增删/叠加/递减、发牌、每回合开始的结算等。 |
| [src/mutators.js](src/mutators.js) | **mutator 函数**（`mutJoin` / `mutStart` / `mutUseSkill` / `mutPlayCard` / `mutBuyCard` / `mutRefreshStore` / `mutRoll` / `mutEndTurn` 等）——纯函数，输入当前房间状态、输出新状态或报错，是游戏规则真正跑的地方。加新效果基本就是在这几个函数里加分支。这些函数直接在浏览器里跑（Supabase 的乐观锁允许这样做，不需要像上一版 CloudBase 那样单独部署一个云函数）。 |
| [src/app-state.js](src/app-state.js) | 运行时可变状态（是否已连上共享存储、我的身份、当前房间号、UI 状态）放在一个共享 `runtime` 对象里，供 app.js 和 render.js 一起读写。 |
| [src/render.js](src/render.js) | 所有渲染函数——纯字符串拼 HTML 再整体替换，没有用框架。 |
| [src/app.js](src/app.js) | 入口：房间创建/加入/订阅、事件委托、启动逻辑；`withGameLock` 包一层调用 mutator、转发给 supabase-db.js 的乐观锁写回。 |
| [src/supabase-config.js](src/supabase-config.js) | 你自己 Supabase 项目的 URL 和 anon key——部署前必须把占位符换成真实值。 |
| [src/supabase-db.js](src/supabase-db.js) | 浏览器这一侧的数据库封装：`getGame` / `subscribeGame`（直接读/监听数据库）、`runGameTransaction`（乐观锁：读 version → 跑 mutator → 带 version 条件写回，冲突就重读重试）、`createRoom`。 |
| [src/vendor/supabase.umd.js](src/vendor/supabase.umd.js) | Supabase 浏览器 SDK，直接提交进仓库、跟着 Netlify 一起发布——**没有走 jsdelivr/unpkg 这类第三方 CDN**，因为它们在中国大陆经常被 DNS 污染（详见下面"部署前需要做的事"上方的说明）。升级 SDK 版本就是重新下载这个文件替换掉。 |
| [src/style.css](src/style.css) | 全部样式，`index.html` 用 `<link>` 直接引用。 |
| [supabase-setup.sql](supabase-setup.sql) | 建表 + 安全策略 + 打开实时推送的 SQL，在 Supabase 控制台的 SQL Editor 里跑一次即可。 |

## 如何开发 / 更新线上版本

改 `src/` 下对应模块的代码，直接用浏览器打开（需要经过一个静态服务器，比如 `npx serve`——
ES module 走 `file://` 协议在部分浏览器里会被 CORS 拦住）验证没问题后提交、push，Netlify
会自动重新部署。**没有构建步骤，也没有需要单独部署的云函数**——`index.html` 和 `src/*.js`
就是线上跑的代码本身，改完就是改完。
